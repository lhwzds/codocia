# Codocia

<sub>[English](../README.md) · **中文**</sub>

Codocia 是给 AI 编程智能体用的笔记本和编译器：智能体阅读仓库，保存引用代码的简短笔记；代码变动时，Codocia 负责让这些笔记保持可信。本书面向准备修改 Codocia 的工程师，讲清它如何工作、为什么这样设计。

3. [结构、翻译与构建](03-output.md) — 生成的结构图 · 不会悄悄漂移的翻译 · build 写出什么 · 移动固定提交
